# Toolbelt Web (HTML/CSS/JS)

A browser-based utility tool built with plain HTML, CSS, and JavaScript.

## Features

- Password generator with optional symbols
- SHA-256 / SHA-384 / SHA-512 text hashing
- JSON validation and pretty formatting (optional key sort)
- Duplicate file finder for selected files (SHA-256)

## Run

Just open `index.html` in your browser.

For local development with a tiny server:

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

## Files

- `index.html` UI structure
- `styles.css` styling
- `app.js` browser logic
